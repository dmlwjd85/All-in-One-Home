# 하단 버튼의 손맛

컵 그림과 호일이 벗겨지는 연출은 이 문서의 범위가 아닙니다. 그 그림은 가계부 팀 완성본이 오면 버튼 안에 그대로 넣습니다. 여기에는 그림 바깥의 누름, 소리, 진동만 적습니다. 그림이 바뀌어도 `press-feel` 틀은 그대로 둡니다.

누르는 즉시 빠른 입력칸이 열립니다. 스프링이 끝날 때까지 기다리지 않습니다. 포커스는 탭 처리 안에서 바로 줍니다.

## 말랑한 누름

누름은 포인터를 내리는 순간과 떼는 순간으로 나눕니다.

- 내리는 순간 컵이 가로로 조금 퍼지고 세로로 눌립니다. 부피를 거의 유지하는 찌부러짐입니다. 손을 떼기 전까지 그 모양으로 머뭅니다.
- 떼는 순간 감쇠 조화 진동으로 돌아옵니다. `x'' + 2ζω x' + ω² x = 0`. 보통은 ζ 0.38이라 제자리를 살짝 넘긴 뒤 앉습니다. 움직임 줄이기는 ζ 0.95라 넘김이 거의 없고, 찌부러짐도 더 작습니다.
- 다시 누르면 진행 중인 스프링을 끊고 같은 요소에서 다시 시작합니다. 위치와 크기를 레이아웃으로 읽지 않고 `transform`만 바꿉니다.

스프링으로 버튼이 통 튀게 만드는 방법은 게임과 인터페이스에서 같은 이차 미분을 샘플링하는 쪽입니다. 디즈니의 찌부러짐과 늘어남(Frank Thomas, Ollie Johnston, *The Illusion of Life*)은 누를 때 납작해졌다가 돌아올 때 반대로 조금 길어지는 비례입니다.

## 뽁과 톡

소리는 녹음 파일이 아닙니다. 뽁은 내려가는 사인파와 아주 짧은 공기 잡음, 톡은 더 높고 더 짧은 튕김입니다. 버튼 소리와 글자 소리가 쓰는 오디오 컨텍스트 하나를 그대로 쓰고, 동시에 네 개까지만 두며, 그보다 오래된 소리는 12ms에 사그라지게 한 뒤 tanh 리미터를 통과합니다.

기본은 글자 소리와 같이 꺼져 있습니다. 저장 키는 `ssug-gyomu-press-feel`이고, 값이 `1`일 때만 소리와 진동이 납니다. 콕 소리의 저장 키는 바꾸지 않았습니다. 손맛을 끄면 진동도 같이 꺼집니다. 찌부러짐 자체는 소리 설정과 별개로 남습니다.

## 진동

`navigator.vibrate`는 블링크에서만 구현되어 있습니다. W3C Vibration API 구현 보고서(2026년 4월 소스 확인)와 MDN, Can I use를 기준으로 하면 아래와 같습니다.

| 기기 | 엔진 | 웹에서 진동 |
| --- | --- | --- |
| 아이폰·아이패드 Safari, iOS의 크롬·파이어폭스 | WebKit | 없음. WebKit은 이 API를 넣은 적이 없고, 표준안에 반대합니다. |
| 맥 Safari | WebKit | 없음 |
| 안드로이드 크롬, 삼성 인터넷, 엣지, 오페라 | Blink | 있음. 사용자가 한 번 누른 뒤에만 되고, 무음·방해금지에 막힐 수 있습니다. 이 버튼은 14ms만 울립니다. |
| 데스크톱 크롬 | Blink | 함수는 있으나 떨릴 모터가 없는 경우가 많습니다. 호출이 참이어도 몸이 느끼지 못할 수 있습니다. |
| 파이어폭스 129 이후, 안드로이드 파이어폭스 | Gecko | 지원을 뺐거나 환경설정으로 꺼 두어 모터가 울리지 않습니다. |

아이폰 Safari가 웹 진동을 지원하지 않는다는 말은 2026년 10월에도 맞습니다.
