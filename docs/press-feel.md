# 하단 버튼의 손맛

컵 그림과 0.52초 연출은 가계부 완성본(`cupD.plain.css`, `fabPop.js`)을 그대로 씁니다. 누름 크기도 그 컵에 맞춘 가로 1.1·세로 0.86, 놓을 때 0.46초 되튐 곡선입니다. 예전 바깥 스프링(더 크게 찌그러지고 여러 번 흔들림)은 이 그림과 겹쳐 컵이 두 번 눌려 빼 두었습니다.

소리는 완성본의 뽁·톡 곡선입니다. 재생만 교무수첩의 오디오 컨텍스트 하나와 리미터를 탑니다. 컨텍스트를 새로 만들지 않습니다. 아이폰은 `ambient`라 무음 스위치를 지키고, 듣던 음악도 끊지 않습니다.

누르는 즉시 빠른 입력칸이 열립니다. 껍질 연출이 끝날 때까지 기다리지 않습니다. 포커스는 탭 처리 안에서 바로 줍니다.

## 말랑한 누름

누름은 포인터를 내리는 순간과 떼는 순간으로 나눕니다.

- 내리는 순간 컵이 가로 1.1, 세로 0.86으로 0.07초 만에 눌리고, 손을 떼기 전까지 그 모양으로 머뭅니다.
- 떼는 순간 0.46초 동안 `cubic-bezier(.28, 1.9, .42, .9)`로 한 번 넘었다가 앉습니다. 움직임 줄이기에서는 이 눌림을 끄고, 접시에 0.16초 색만 번쩍입니다.
- 위치와 크기를 레이아웃으로 읽지 않고 `transform`만 바꿉니다.

되튐 곡선은 완성본이 이 컵에 맞춰 둔 한 번의 넘김입니다. 디즈니의 찌부러짐과 늘어남(Frank Thomas, Ollie Johnston, *The Illusion of Life*)처럼 누를 때 납작해졌다가 돌아올 때 반대로 조금 길어집니다. 크기 변화는 완성본처럼 14% 안으로 두어 호일 글자가 뭉개지지 않습니다.

## 뽁과 톡

소리는 녹음 파일이 아닙니다. 뽁은 560Hz에서 210Hz로 내려가는 75ms 사인과 배음이고, 톡은 880Hz에서 1560Hz로 올라가는 55ms에 짧은 딸깍이 있습니다. 호일이 벗겨지는 0.09초에 톡이 납니다. 버튼 소리와 글자 소리가 쓰는 오디오 컨텍스트 하나를 그대로 쓰고, 동시에 네 개까지만 두며, 같은 소리는 45ms 안에 다시 내지 않습니다. 그보다 오래된 소리는 12ms에 사그라지게 한 뒤 tanh 리미터를 통과합니다. 음높이는 매번 ±5% 달라집니다.

기본은 글자 소리와 같이 꺼져 있습니다. 저장 키는 `ssug-gyomu-press-feel`이고, 값이 `1`일 때만 소리와 진동이 납니다. 버튼 소리의 저장 키는 바꾸지 않았습니다. 손맛을 끄면 진동도 같이 꺼집니다. 찌부러짐 자체는 소리 설정과 별개로 남습니다.

## 진동

`navigator.vibrate`는 블링크에서만 구현되어 있습니다. W3C Vibration API 구현 보고서(2026년 4월 소스 확인)와 MDN, Can I use를 기준으로 하면 아래와 같습니다.

| 기기 | 엔진 | 웹에서 진동 |
| --- | --- | --- |
| 아이폰·아이패드 Safari, iOS의 크롬·파이어폭스 | WebKit | 없음. WebKit은 이 API를 넣은 적이 없고, 표준안에 반대합니다. |
| 맥 Safari | WebKit | 없음 |
| 안드로이드 크롬, 삼성 인터넷, 엣지, 오페라 | Blink | 있음. 사용자가 한 번 누른 뒤에만 되고, 무음·방해금지에 막힐 수 있습니다. 이 버튼은 12ms만 울립니다. |
| 데스크톱 크롬 | Blink | 함수는 있으나 떨릴 모터가 없는 경우가 많습니다. 호출이 참이어도 몸이 느끼지 못할 수 있습니다. |
| 파이어폭스 129 이후, 안드로이드 파이어폭스 | Gecko | 지원을 뺐거나 환경설정으로 꺼 두어 모터가 울리지 않습니다. |

아이폰 Safari가 웹 진동을 지원하지 않는다는 말은 2026년 10월에도 맞습니다.
