화면은 580쪽 교무수첩 한 권이다. 해시 `#p쪽번호`로 쪽을 연다. 로그인 전에는 시작 화면만 보인다.

## 2. 항상 있는 크롬 (표지 제외 탭은 용지 안)

도구막대 (모든 쪽, 표지 포함):

- 브랜드 「2026 교무수첩」, 현재 쪽 제목, 쪽번호 `p.쪽/580` (너비 700 이하에서는 `p.쪽`)
- 사용자 이름, 손님이면 「이 기기」
- `찾기` (Ctrl/Cmd+K), `내보내기`, `가져오기` (JSON 파일, 8MB 초과 거절), `로그아웃` 또는 `나가기`
- 인쇄에서는 도구막대를 숨김

용지 탭 (2쪽부터):

- 왼쪽 14개: 홈(2), 쓱적(496), 연간(32), 주간(46), 하루(99), 학급(140), 학생(154), 출결(231), 상담(256), 수업(335), 업무(404), 태그(9), 공책(516), 칠판(559). 현재 구간은 `aria-current="page"`

- 휴대폰(700px 이하)에서는 탭이 가로로 스크롤되고, 더 있다는 힌트가 보임
- 쪽 상단 `이전`/`다음`/`홈` 등 PDF 상단 링크를 버튼으로 표시
- 바닥 `p.쪽`, `ⓒJ쌤`
- 방향키 ←/→, PageUp/PageDown으로 앞뒤 쪽, Home은 2쪽
- 오른쪽 아래 `쓱적` (Alt+S): 한 줄 입력, `적기`, `닫기`. 건강·민원·학폭이 들어가면 이 기기에만 저장

찾기 대화상자: 검색 입력, 결과 버튼(그 쪽으로 이동), `닫기`.

쪽을 못 읽으면: 「쪽을 불러오지 못했습니다.」와 `다시 불러오기`.

- 건강·민원·학폭 문장은 `homenote_v2_ssugeokSensitive`에만 두고 Firestore로 올리지 않음

## 5. 저장

로컬 키 (이름을 바꾸거나 늘리지 않음):

- `homenote_guest`
- `homenote_v2_notebookFields_p{쪽}` — 쪽 칸
- `homenote_v2_ssugeokSensitive`
- `homenote_v2_` + 목록 이름: `ssugeokInbox`, `studentNotes`, `counselNotes`, `teacherPlans`, `teacherTodos`, `teacherAttend`, `classRoster`, `ledgerTx`, `ledgerBudgets`, `teacherLessons`, `teacherMeets`, `teacherContacts`, `teacherTimetable`, `familyDiary`, `ddayCards`, `submissionSheets`
- `homenote_v2_praiseBoard`

Firestore (로그인했을 때, 경로 유지):

- 목록: `artifacts/{appId}/public/data/{목록이름}/{문서}`
- 칭찬: `artifacts/{appId}/public/data/praiseBoard/board`
- 쪽 칸: `artifacts/{appId}/public/data/notebookFields/p{쪽}` (`fields`, `page`)
- 로컬 전용 쪽(19–22, 157–158, 323–334)과 민감 쓱적은 클라우드로 쓰지 않음
- 쪽 칸은 약 400ms 뒤 클라우드에 합침. 실패하면 토스트와 다시 시도. 기기 복사본은 남음

내보내기 JSON은 위 목록·칭찬·쪽 칸·민감 메모를 담는다. 가져오기는 덮어쓰기 또는 같은 id·같은 칸만 합친다. 로그인 중이면 클라우드 문서도 갱신하고, 백업에 없는 클라우드 문서는 지우지 않는다.

명렬의 이름·성별·생년월일이 비어 있거나 예전 값과 같으면 학생 카드(159, 161, …)로 이어 저장한다.

장부·일기 등 예전 홈노트 목록은 화면 입력 없이 내보내기에만 남는다.
