# 쨈 교무수첩에 있는 것

- 오늘 한 화면: 다음 교시, 결석·지각, 할 일 수, 큰 입력, 바로가기 여섯, 시간표, 할 일, 이번 주 일정, 최근 기록
- 빠른 기록: 관찰, 상담, 할 일, 일정, 알림장, 메모, 칭찬, 보호자
- 출결은 예외만 저장. 칸이 없으면 출석
- 학생별 기록과 나이스에 옮길 것 모음
- 명렬 붙여넣기: 엑셀·한글 표·나이스 화면 복사를 그대로. 띄운 번호(51번 등)와 60명까지, 넣기 전에 미리보기
- 새 명단은 같은 번호라도 이름이 다르면 새 학생. 빠진 학생은 지난 명단으로 남고 기록·출결은 그대로
- 엑셀 내려받기: 출결(이 달·1학기·2학기, 학생×날짜 표와 합계), 기록(반 전체·학생 한 명)
- 할 일 걷기, 알림장 복사, 시간표, 공휴일
- 다크 모드, 구석 팁, 오프라인 저장, 홈 화면 설치
- 공용 컴퓨터: 30분이면 화면을 잠그고, 클라우드가 연결되면 메모리에만 둠
- 첫 실행 백업 후 한 번 옮기기. 민감 기록·연락처·주소는 이 기기만
- 백업 내려받기와 가져오기. 예전 형식도 받음
- 공개 경로 정리는 확인 문장 뒤에만

클라우드 로그인과 실시간 동기화는 설정값이 오면 같은 구조에 붙입니다.
