# 할 일 동기화 규칙 메모

## updatedAt이 없는 쓰기는 일부러 허용합니다 (v46 호환)

- `firestore.rules`의 `todoClockOk`는 hlc가 없는 문서에서 더 이른 `updatedAt`으로 덮는 쓰기를 거절합니다.
- 다만 **`updatedAt` 칸이 없는 쓰기는 이 비교를 거치지 않습니다.** 이것은 허점이 아니라 v46 호환을 위해 일부러 둔 것입니다.
  - v46 기기는 hlc를 모르고, `updatedAt`을 빼고 쓰거나 serverTimestamp로만 씁니다.
  - 이 쓰기까지 막으면 v46 기기에서 할 일 저장이 끊겨 기기 사이 자료가 어긋납니다.
- v47 이후가 한 번이라도 쓴 문서(hlc 있음)는 따로 보호합니다. `updatedAt` 없이 merge로 바꾸는 쓰기는 거절합니다.
- 시각이 불확실한 문서(`u: true`)는 시각이 확실한 쓰기가 더 이른 시각으로도 덮을 수 있습니다. 그 대신 앱이 충돌 사본을 남깁니다.
- 모든 v46 기기가 새 판으로 바뀐 뒤에는 `updatedAt`을 필수로 바꾸는 것을 검토합니다.

시험: `npm run check:twodevice` (에뮬레이터)
