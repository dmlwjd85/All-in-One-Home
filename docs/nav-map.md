# 화면 지도

| 화면 | 주소 | 하는 일 |
|---|---|---|
| 오늘 | `#/today` | 다음 교시, 출결, 할 일, 쨈 버튼, 시간표, 일정, 최근 기록 |
| 빠른 입력 | 쨈 버튼 또는 `/` | 종류, 학생, 한 줄, 저장. `@번호` `#태그` `내일`, 본문 속 이름 연결 |
| 출결 | `#/attend/날짜` | 안 온 친구만 누름. 길게 누르면 사유 |
| 학생 기록 | `#/students` | 번호순 목록 |
| 학생 | `#/students/번호` | 관찰·상담·칭찬·보호자, 기간(이번 달·1학기·2학기·올해)으로 거르기, 이 학생 기록 복사 |
| 나이스 | `#/students/neis` | 옮길 기록만 모아 복사 |
| 일정 | `#/schedule` | 주간, 월간, 시간표 |
| 할 일 | `#/todo` | 할 일, 걷기, 메모 |
| 알림장 | `#/notice` | 복사해서 다른 곳에 붙이기 |
| 설정 | `#/settings` | 밝기, 공용 컴퓨터, 백업, 옮기기, 공개 경로 |
| 예전 쪽 | `#/legacy/쪽` | 읽기만 |

예전 `#p154`, `#/cards/3`, `#/write` 같은 주소는 가까운 새 화면으로 바꿉니다.
