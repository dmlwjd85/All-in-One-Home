# 키보드 테마 (모양·소리)

설정 → 화면 → **키보드 테마**에서 여섯 가지를 고릅니다. 값은 이 기기의 `localStorage` 키 `ssug-gyomu-kb-theme` 에만 둡니다. 기록·클라우드(Firestore)·로그인에는 넣지 않습니다.

| 테마 | 모양 | 밝게 / 어둡게 |
| --- | --- | --- |
| MX 미니 (기본) | **지금 앱 키캡 그대로**(베이지 볼록, 장미색 + 키캡). 따로 스타일을 받지 않습니다 | 지금과 같음 |
| 기계식 레트로 | 크림색 높은 키, 아래 치마 그림자, 모서리 8px, 3px 눌림 | 밝은 크림 / 짙은 갈색 |
| 노트북 슬림 | 얇은 판, 1px 테두리, 모서리 6px, 1px 눌림 | 흰 판 / 짙은 회색 |
| 파스텔 마시멜로 | 분홍 말랑 키, 부드러운 그림자, 모서리 22px, 3px 눌림 | 연분홍 / 짙은 자두색 |
| 젤리 투명 키 | 반투명 유리 키, 흰 테두리, 안쪽 빛, 2px 눌림 | 반투명 흰색 / 반투명 어둠 |
| 타자기 | 상아색 둥근 키, 2px 금속 테, 3px 눌림 | 상아 / 짙은 먹색 |

- 눌림은 위치 이동(`translateY`)으로만 나타냅니다. 키를 납작하게 줄이지(scaleY) 않습니다.
- 글꼴·글자색·화면 바탕은 바꾸지 않습니다. 글자 대비는 모든 테마 키 바탕에서 4.5 이상입니다(`npm run check:kbtheme`).
- 테마를 바꾸면 누른 곳에서 원이 퍼지며 새 모양이 드러납니다(View Transition, 0.42초). 움직임 줄이기를 켠 기기와 이 기능이 없는 브라우저는 바로 바뀝니다.
- 첫 화면 묶음에는 들어가지 않습니다. 테마 스타일(`src/ui/kbtheme.css`)은 다른 테마를 쓰거나 설정을 열 때만 받고, 소리 파일은 테마 소리를 고른 뒤에만 받습니다.
- 다른 테마를 저장해 둔 기기는 앱을 열 때 스타일을 받는 잠깐(보통 수십 ms, 설치 앱은 미리 저장됨) 기본 모양이 보였다가 바뀝니다.

## 테마 소리

설정 → 소리에서 'MX 테마'·'레트로 테마'처럼 **… 테마** 칩으로 고릅니다(제목 줄 없이 칩 이름으로 알려서 360×844에서도 소리 칩이 탭바에 가리지 않습니다). 기존 소리(몽글·몽돌·축 소리 등)와 같은 자리(`ssug-gyomu-key-voice`)에 `kb-<테마>` 로 저장합니다. 고르지 않은 사람의 소리는 바뀌지 않습니다. 테마 소리를 쓰는 중에 모양 테마를 바꾸면 소리도 같은 테마로 옮겨 갑니다.

- 크기는 `KB_VOICE_GAIN`(0.09) × #42의 계단(작게·보통·크게 = 1·2·3배)입니다. 0.09는 옮겨 온 글자 소리(0.032 기준)와 처음 30ms 에너지가 비슷해지는 값입니다. 파일 받기·고르기는 `src/ui/kbsound.js`에 두고 keyfeel.js에는 몇 줄만 이어 붙였습니다.
- 누름 한 번에 소리 하나, 뗄 때 하나입니다. 같은 녹음을 연달아 쓰지 않습니다. 빠른 연타는 기존 소리와 같은 규칙(앞 소리를 짧게 접기, 동시에 최대 6개)을 따릅니다.
- 소리 끄기, 크기(작게·보통·크게), 진동, 받아쓰기 중 끄기를 그대로 따릅니다.
- 파일을 다 받기 전의 누름은 조용히 지나갑니다(반쪽 소리를 내지 않음). 오프라인에서는 한 번 받은 뒤부터 들립니다.
- 파일: `public/sounds/kb/<테마>-d<n>.wav`(누름), `-u<n>.wav`(뗌). 32kHz 모노 16비트, 28개 410,606바이트. 시연판(5차)과 같은 대역·잔향을 미리 입혀 구웠고, 여섯 테마 크기 균형도 시연판과 같습니다.
