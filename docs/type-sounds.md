# 글자 소리

글을 적을 때 나는 소리 네 가지는 모두 앱 안에서 Web Audio로 직접 합성합니다. 녹음 파일을 저장소에 넣지 않았고, 외부 음원도 쓰지 않습니다. 받을 라이선스는 없습니다.

합성 코드는 `src/ui/typesound.js` 입니다.

| 이름 | 듣는 느낌 | 만드는 방법 |
|---|---|---|
| 뽁 | 통통 튀는 팝 | 높은 음이 금방 낮아지는 짧은 사인파와 시작 잡음 |
| 띵 | 작은 실로폰 | 쇠막대처럼 배음이 있는 사인파, 빠르게 사그라듦 |
| 물방울 | 떨어지는 방울 둘 | 높은 음이 미끄러져 내리는 방울을 두 번 |
| 방귀 | 짧고 낮은 뿌우 | 내려가는 사인파와 걸러진 잡음을 살짝 떨리게 겹침 |

설정에서는 뽁, 띵, 물방울을 먼저 두고, 방귀만 ‘장난 소리’ 아래에 둡니다.

기본은 꺼져 있습니다. 켠 뒤의 처음 소리는 뽁입니다. 크기는 교실에서 쓰도록 작게 고정해 두었고, 버튼 소리의 ‘작게’와는 따로입니다. 비밀번호 칸과 암호·카드 번호처럼 보이는 칸에서는 소리를 내지 않습니다.
