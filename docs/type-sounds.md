# 글자를 적을 때 나는 소리

열 가지 모두 이 앱 안에서 직접 합성합니다. 녹음 파일을 넣지 않았고, 영상에서 잘라 쓰지도 않았습니다. 따라서 라이선스 링크는 없습니다.

치는 순간은 감쇠하는 배음 몇 개와 짧은 잡음입니다. 축마다 클릭, 걸림, 바닥을 치는 시각이 다릅니다. 글자마다 음높이와 세기를 조금 흔들고, 스페이스는 더 낮고 길게, 엔터는 짧은 종을 섞고, 지우기는 더 짧고 높게 냅니다. 방귀만 낮은 음이 떨리는 장난 소리입니다.

빠른 연타는 소리를 여섯 개까지만 겹치고, 그보다 오래된 소리는 16ms 동안 사그라지게 합니다. 글자 소리는 버튼 소리와 같은 오디오 컨텍스트 하나로 모은 뒤, 리미터를 통과합니다. 파형 앞뒤는 0으로 페이드합니다.

기본은 꺼져 있습니다. 켠 뒤의 처음 소리는 적축입니다. 설정에서 열 가지를 미리 들을 수 있고, 방귀는 ‘장난 소리’ 아래에 둡니다. 비밀번호 칸과 암호·카드 번호처럼 보이는 칸에서는 소리를 내지 않습니다.

| 소리 | 듣는 느낌 | 만드는 방법 |
| --- | --- | --- |
| 적축 | 한 번의 짧은 타건 | 중간 배음과 짧은 잡음이 같이 바닥을 침 |
| 갈축 | 걸림 뒤의 타건 | 높은 걸림을 먼저 두고, 낮은 바닥 소리를 조금 늦게 |
| 청축 | 날카로운 딸깍 | 아주 높은 클릭을 앞에 두고, 몸통 소리는 뒤에 |
| 흑축 | 묵직한 바닥 | 낮은 배음이 길게 남고 잡음은 적음 |
| 무접점 | 둥근 고무 | 낮은 배음이 천천히 올라와 길게 남음 |
| 저소음 | 패드에 묻힌 짧은 소리 | 배음은 작게, 잡음만 아주 짧게 |
| 타자기 | 금속 막대 | 높은 배음과 밝은 잡음. 엔터에는 종 |
| 노트북 | 고무 돔 | 짧은 잡음이 낮은 배음을 덮음 |
| 크림 | 윤활된 낮은 소리 | 낮은 배음이 늦게 한 번 더 따라옴 |
| 방귀 | 뿌우 | 낮아지는 사인파와 걸러진 잡음을 떨리게 겹침 |

참고한 방식은 기계식 키보드를 합성으로 흉내 내는 쪽입니다. 바닥을 치는 소리와 클릭을 시간으로 나누고, 배음은 지수로 감쇠하는 사인파로 둡니다. 영상이나 상용 샘플은 쓰지 않았습니다.
