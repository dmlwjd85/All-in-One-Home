# 예전 수첩에서 넘어온 것

| 예전 | 지금 |
|---|---|
| 오늘·콕, 적 | 오늘 홈과 빠른 입력 |
| 명렬표, 누가, 상담, 보호자 | 학생 기록 |
| 출결 주간 표 | 하루 예외 출결. 주간 표 원본은 보관 |
| 달력, 시간표 | 일정 화면 |
| 할 일, 제출 | 할 일과 걷기 |
| 알림장 | 알림장 |
| 건강·학폭·민원, 연락처, 주소 | 이 기기에만 |
| 학급 회계, 회의, 수업 노트 | 보관함. 새 화면의 본 기능은 아님 |
| 580쪽 입력 | 필요한 쪽은 읽기 전용 |

원본 `homenote_` 키는 읽기만 합니다. 옮긴 뒤에도 그 키는 그대로 둡니다.
