# 기능 대응

`docs/feature-inventory.md`의 항목이 이번 메뉴·화면 개편 뒤에도 같은 자리에서 동작하는지 적는다. 저장 키와 Firestore 경로는 바꾸지 않았다.

검증: `npm run check:links`, `check:hits`, `check:storage`, `check:quality`, `check:browser`(390·360·720·768·800·900·1023·1024·1366·1920). 브라우저 검사는 580쪽을 모두 열고, 메뉴의 현재 위치·앞쪽 빈칸·입력 자리글·선택 상자·말줄임·탭·브랜드·겹침·선택 대비를 함께 본다. 아래 표의 「확인」은 그 검사와 프로덕션 미리보기에서 대표 쪽을 연 결과다.

## 항상 보이는 메뉴 (추가)

쪽 기능은 빼지 않고, 어디로든 1–2번에 가게 메뉴만 더했다.

| 메뉴 | 주소 | 쪽 |
| --- | --- | --- |
| 표지 | `#/cover` | 1 |
| 홈 | `#/home` | 2 |
| 연간 | `#/year` | 32 |
| 월간 | `#/month/해/달` | 34–45. 주간 쪽에서는 그 주가 속한 달 |
| 주간 | `#/weeks`, 각 주 `#/week/주차` | 46, 47–98 |
| 학사 | `#/schedule` | 33 |
| 하루 | `#/days`, `#/day/번호` | 99, 100–139 |
| 학급·학생·출결·상담·수업·업무 | `#/class` `#/students` `#/attend` `#/counsel` `#/lesson` `#/work` | 140, 154, 231, 256, 335, 404 |
| 쓱적·공책·칠판·스티커·태그 | `#/write` `#/notebook` `#/board` `#/stickers` `#/tags` | 496, 516, 559, 563, 9 |
| 시간표·학생카드·예산 | `#/timetable` `#/cards` `#/cards/번호` `#/budget` | 141, 159(1번), 161(2번)…, 468. 막대에 항상 보여 한 번에 감 |
| 전체 → 새 학기, 사용법, 달 12개, 기한, 예산, 찾기 | `#/prep` `#/guide` `#/deadlines` `#/budget` 등 | 3, 5, 405, 468 |
| 날짜 | `#/date/해-달-날` | 그 주 주간 쪽. 맞는 날짜 주소는 바꾸지 않음 |
| 예전 주소 | `#p쪽`, `#/p/쪽` | 1–580은 같은 쪽. 열리면 이름 있는 주소로 바꿈. `#p999`처럼 580을 넘으면 580쪽으로 옮기고 안내 |
| 없는 주소 | `#/없는이름`, `#p0`, 없는 주·하루·날짜, 해와 달이 어긋난 월, `#/cards/abc`·`#/cards/-1`·`#/cards/2.5` | 가까운 쪽으로 옮기고 짧은 안내. 잘못된 학생 카드는 `#/cards` |

메뉴는 도구막대 아래 한 줄이다. 1024px 너비에서는 메뉴 칸 높이가 44px이다. 휴대폰에서는 그 바로가기 줄이 52px이고, 칸과 화살표의 터치 크기는 가로·세로 44px 이상이다. 800px 이하에서는 시간표·학생카드·예산 핀을 막대에서 빼고 `전체`에 둔다. 그래서 360·390의 메뉴 창에는 항목이 세 개 이상 보인다. 화면 높이가 820px 이하면 도구와 같은 줄에 두어 용지 높이를 지킨다. 쪽 제목이 메뉴를 누르지 않는다. 칸이 모자라 글자가 반만 보이면 그 칸은 접고, 앞·뒤 화살표는 보이는 폭의 약 70%만큼 옮긴다. 지금 구역은 `aria-current="page"`이고, 쪽이나 주소가 바뀔 때만 가운데로 맞춘다. 스크롤하는 동안에는 다시 가운데로 당기지 않는다. 뒤로 가기는 `pushState`라 직전 해시로 돌아가며, 그때 전체 메뉴는 닫힌다. `check:browser`가 연간→월간→주간→학사→하루, 4월 날짜, 주간에서 월간, 전체에서 예산, 시간표·학생카드·예산 칩, 1024·390·360 메뉴 스크롤, `#/cards/2`, 없는 주소를 확인한다.
