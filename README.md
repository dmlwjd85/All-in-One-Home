# 콕 교무수첩

초등 담임이 열자마자 출결·기록·할 일을 남기는 교무수첩입니다. 주소는 그대로입니다.

https://dmlwjd85.github.io/All-in-One-Home/

## 쓰는 법

1. 처음 열면 이 기기에서만 쓸지, 구글 계정으로 연결할지 고릅니다. 연결 설정이 없으면 이 기기에만 저장됩니다.
2. 예전 교무수첩 기록이 이 기기에 있으면, 백업 파일을 만든 다음 옮길지 묻습니다. 원본 키는 지우지 않습니다.
3. 홈에서 출결과 다음 교시를 보고, 가운데 콕 또는 `콕, 적`으로 한 줄을 남깁니다.
4. 컴퓨터에서는 `/` 키로 바로 적을 수 있습니다.
5. 설정에서 다크 모드, 공용 컴퓨터 모드, 백업, 기록 옮기기, 예전 공개 경로 정리를 합니다.
6. 설정 > 화면에서 버튼을 누를 때 소리를 고릅니다. 몽글, 몽돌, 적축, 갈축, 청축, 끌기이고 기본은 몽글입니다. 크기는 작게, 보통, 크게이고 기본은 작게입니다.

화면 아래(휴대폰): 오늘 · 출결 · 콕 · 기록 · 일정. 넓은 화면은 왼쪽 메뉴입니다.

## 저장

- 이 기기 저장소 이름 `ssug-gyomu`, 민감 기록은 `ssug-gyomu-local`.
- 구글 로그인 뒤에는 `users/{uid}` 아래만 읽고 씁니다. 본인만 가능합니다. 인터넷이 끊겨도 이 기기에 남고, 연결되면 이어서 올립니다.
- 건강·보건·알레르기·투약·학폭·민원, 보호자 연락처, 주소, 예시 학급은 클라우드로 보내지 않습니다. 민감 낱말은 `src/lib/sensitive.js` 한 목록이고, 보안 규칙 `safeText`도 그 목록과 같습니다. 학생 메모만 민감하면 이름과 번호는 올리고, 메모는 이 기기에 둡니다.
- 예전 공개 경로에는 새 기록을 쓰지 않습니다. 지우기는 설정에서 `지우기`라고 확인한 뒤에만 됩니다. 그 경로는 예전 프로젝트 설정이 따로 있어야 목록이 열립니다.
- 배포된 규칙에 없는 칸은 이 기기에만 둡니다. 교시 시각 전체, 걷기에서 남은 번호, 나이스에 옮겼다는 표시가 그렇습니다. 출결은 화면에 한국어로 보이고, 올릴 때만 규칙에 맞는 값으로 바꿉니다.

## 클라우드 연결

앱은 환경 변수 `VITE_FIREBASE_CONFIG` 하나만 읽습니다. 값은 웹 설정 JSON을 한 줄로 붙인 문자열입니다. 파일로 저장소에 넣지 마세요.

깃허브 페이지에 실을 때:

1. 저장소의 Settings, Secrets and variables, Actions 로 갑니다.
2. New repository secret 을 누릅니다.
3. 이름은 `VITE_FIREBASE_CONFIG` 입니다.
4. 값에는 웹 설정 JSON 한 줄을 넣습니다. 이 설명에 그 값을 적지 않습니다.
5. 설치·빌드와 브라우저 확인 단계가 그 비밀을 읽습니다. 풀 리퀘스트 검사에도 같은 비밀을 씁니다. 값은 로그에 찍지 않습니다.

로컬에서 연결해 보려면 같은 변수를 현재 터미널에만 넣고 개발 서버를 띄웁니다. `.env` 를 만들어 두어도 저장소에는 올라가지 않습니다. 작업이 끝나면 그 변수를 지웁니다.

규칙이 저장소의 `firestore.rules` 와 같다면, 다시 배포는 총괄 쪽에서 `firebase deploy --only firestore:rules --project ssug-gyomu` 로 합니다. 키나 토큰은 올리지 않습니다.

## 버튼 소리

소리 파일은 받지 않습니다. 브라우저가 누를 때와 뗄 때 파형을 바로 만들고, 높이를 조금씩 바꿉니다. 가져온 녹음이 없어서 따로 밝힐 음원 라이선스는 없습니다. 말로 적는 동안에는 소리를 내지 않습니다. 소리를 꺼 두어도 설정의 칩에서는 미리 들어 볼 수 있습니다. 처음에는 `콕, 누를 때 소리가 나요` 안내가 팁으로 남고, 끄기를 누르면 소리가 꺼집니다.

## 글꼴과 색

글꼴은 `src/styles/tokens.css` 의 `--font-title`, `--font-body` 두 줄만 바꾸면 됩니다. 제목은 나눔스퀘어라운드, 본문은 프리텐다드입니다. 바탕은 하늘, 카드는 크림, 포인트는 라벤더입니다. 노랑과 핑크는 글자색으로 쓰지 않습니다.

## 설계와 다른 점

- 색은 하늘 바탕, 크림 카드, 남색 버튼입니다. 아이콘 그림은 따로 있고, 화면 안 클레이 그림은 빈 화면과 저장 순간에만 나옵니다.
- 입력칸 글자는 15px이 아니라 16px입니다. 휴대폰이 칸을 누를 때 화면이 커지지 않게 하려고입니다.
- 토스트에는 이름 전체를 씁니다.
- 1학기 시간표 쪽이 비어 있고 2학기 쪽에 내용이 있으면 2학기를 기본 시간표로 씁니다.
- 손글씨, 학년도 넘기기 버튼은 이번 화면에 없습니다. 학급 회계는 보관함으로만 남깁니다.
- 좁은 화면의 메뉴는 따로 둔 줄 세 개가 아니라 콕 심볼입니다.
- 월 출결은 가로로 긴 표 대신, 친구별 예외 목록입니다.
- 클라우드 교시 시각은 규칙이 시각 하나만 받아서, 여덟 교시 시각은 이 기기에만 둡니다.
- 공개 경로 목록은 예전 프로젝트 설정이 있어야 열립니다.
- 히어로 알약 배경을 조금 어둡게 해 흰 글자 대비를 맞췄습니다.

## 확인하지 못한 것

- 구글 창을 사람이 눌러 끝내는 로그인, 다른 기기에서 같은 기록이 이어지는 것.
- 이미 설치된 휴대폰 앱의 이름·아이콘 갱신, 아이폰 홈 화면 이름.
- 실제 예전 클라우드의 삭제. 예전 프로젝트 설정이 없고, 배포가 데이터를 지우지도 않습니다.
- 선생님 기기의 실제 예전 기록.
