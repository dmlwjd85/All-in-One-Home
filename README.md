# 우리집 홈노트

가계부, 초등 교무일지, 가족다이어리를 한곳에서 오래 쓰기 위한 웹 앱입니다.

배포 주소: https://dmlwjd85.github.io/All-in-One-Home/

## 왜 이렇게 만들었나

최근 가계부·교사 플래너·가족 저널 앱이 공통으로 강조하는 점은 **한눈에 보이는 요약**, **두 탭 안의 핵심 작업**, **검색·내보내기**, **큰 글씨/고대비/44px 터치**입니다. 이 앱은 그 기준을 기본값으로 두었습니다.

- 가계부: 월 수입·지출·여유, 카테고리 예산과 지출 페이스, 고정비 표시, 검색
- 교무일지: 오늘 수업, 수업일지(차시·목표·활동·평가), 할 일, 회의록, 학부모 상담, 출결, 주간 시간표, 학급 명단
- 가족다이어리: 타임라인, 사진, 태그, 검색, 가족/나만 공개, 작성자 표시
- 공통: Google 로그인 동기화 또는 이 기기만 사용, JSON 백업, 키보드 포커스, 본문 건너뛰기, 동작 감소 설정 존중

## 로컬 실행

```bash
npm install
npm run dev
```

## 배포

`main`에 push하면 GitHub Actions가 Pages로 빌드·배포합니다.

Google 로그인을 쓰려면 Firebase Authentication에서 Google 제공업체를 켜고, 승인된 도메인에 `localhost`와 `dmlwjd85.github.io`를 넣어야 합니다.
