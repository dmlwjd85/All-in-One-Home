# 쓱 교무수첩

초등 담임이 열자마자 출결·기록·할 일을 남기는 교무수첩입니다. 주소는 그대로입니다.

https://dmlwjd85.github.io/All-in-One-Home/

## 쓰는 법

1. 처음 열면 이 기기에서만 쓸지 고릅니다. 구글 로그인은 클라우드 설정이 오기 전까지 쉬고 있습니다.
2. 예전 교무수첩 기록이 이 기기에 있으면, 백업 파일을 만든 다음 옮길지 묻습니다. 원본 키는 지우지 않습니다.
3. 홈에서 출결과 다음 교시를 보고, 가운데 ＋ 또는 `쓱, 적`으로 한 줄을 남깁니다.
4. 컴퓨터에서는 `/` 키로 바로 적을 수 있습니다.
5. 설정에서 다크 모드, 공용 컴퓨터 모드, 백업, 기록 옮기기, 예전 공개 경로 정리를 합니다.

화면 아래(휴대폰): 오늘 · 출결 · ＋ · 기록 · 일정. 넓은 화면은 왼쪽 메뉴입니다.

## 저장

- 지금: 이 기기 저장소 `ssug-gyomu`, 민감 기록은 `ssug-gyomu-local`.
- 나중: `users/{uid}` 아래만. 본인만 읽고 씁니다. 설정 파일은 비어 있습니다.
- 건강·알레르기·투약·학폭·민원, 보호자 연락처, 주소는 클라우드로 보내지 않습니다.
- 예전 공개 경로 `artifacts/home-note-app/public/data` 에는 새 기록을 쓰지 않습니다. 지우기는 설정에서 `지우기`라고 확인한 뒤에만 됩니다.

## 글꼴과 색

글꼴은 `src/styles/tokens.css` 의 `--font-title`, `--font-body` 두 줄만 바꾸면 됩니다. 지금은 제목 고운바탕, 본문 프리텐다드입니다. 색은 라일락입니다. 살구는 장식에만 씁니다.

## 설계와 다른 점

- 색은 살구 시안이 아니라 확정된 라일락입니다. 아이콘도 라일락 타일에 흰 ‘쓱’이고, 살구는 작은 점입니다.
- 입력칸 글자는 15px이 아니라 16px입니다. 휴대폰이 칸을 누를 때 화면이 커지지 않게 하려고입니다.
- 토스트에는 이름 전체를 씁니다.
- 1학기 시간표 쪽이 비어 있고 2학기 쪽에 내용이 있으면 2학기를 기본 시간표로 씁니다.
- 손글씨, 학년도 넘기기 버튼은 이번 화면에 없습니다. 학급 회계는 보관함으로만 남깁니다.
- 좁은 화면의 메뉴는 따로 둔 줄 세 개가 아니라 쓱 심볼입니다.
- 월 출결은 가로로 긴 표 대신, 친구별 예외 목록입니다.
- 파이어베이스 값이 없어 로그인과 동기화는 자리만 있습니다. 공개 경로 목록도 예전 프로젝트 설정이 있어야 열립니다.
- 히어로 알약 배경을 조금 어둡게 해 흰 글자 대비를 맞췄습니다.

## 확인하지 못한 것

- 보안 규칙 에뮬레이터를 이 자리에서 다시 돌리지는 않았습니다.
- 이미 설치된 휴대폰 앱의 이름·아이콘 갱신, 아이폰 홈 화면 이름.
- 실제 예전 클라우드의 삭제. 키가 없고, 배포가 데이터를 지우지도 않습니다.
- 선생님 기기의 실제 예전 기록.
